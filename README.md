# Website Project

This project is a full-stack web application that integrates a Progressive Web App (PWA) with a user-friendly interface and robust backend services. The application allows users to perform various actions such as login, registration, browsing, and ordering food. The admin panel provides administrative functions like managing users and viewing orders.

## Features

### Front-End:

- **Framework:** Developed with **Next.js** for server-side rendering, improving SEO and performance.
- **UI Design:** Styled using **Tailwind CSS**, ensuring a responsive and modern design.
- **PWA:** Leveraged Next.js to create a **Progressive Web Application**, allowing users to install the web app on their devices for offline usage.

### Back-End:

- **Express.js** as the backend framework for creating API endpoints.
- **Mongoose** for efficient MongoDB data handling and modeling.

### State Management:

- **Redux Toolkit** for optimized state management, simplifying asynchronous logic and state handling across the app.

### Authentication:

- **NextAuth** for a secure and scalable authentication system, including login, registration, and session management.

### Key Features:

- **User Authentication:** Secure login and registration system.
- **Admin Dashboard:** Manage users, monitor orders, and access analytics.
- **Diet Selection:** Users can choose from different diet plans.
- **Food Ordering System:** Users can order food directly from the app.
- **Blogs:** Content management system to manage and display blogs.
